# PZaaS - Serviço 04 - Pagamento

Documentação web do serviço de Pagamento desenvolvido pela dupla:

- RA 243199
- RA 240080

## Como publicar na Vercel

1. Envie os arquivos desta pasta para um repositório no GitHub.
2. Entre na Vercel.
3. Clique em **Add New > Project**.
4. Importe o repositório do GitHub.
5. Se pedir Framework Preset, use **Other**.
6. Não precisa configurar comando de build.
7. Clique em **Deploy**.

O projeto é um site estático com HTML, CSS e JavaScript.
